# Product Control Plane Server

This directory is the parallel commercial-product/server track for the browser bridge.

Status: architecture/bootstrap work in progress.

The current Ozon Bridge continues to evolve independently under `tooling/llm-api-bridges/ozon-seller/`. This server track must depend on explicit versioned integration contracts rather than on the bridge's internal implementation. When the bridge is ready for commercial integration, the currently accepted bridge version will be attached to these contracts.
