# Клиентский текст рекомендации оберега

Статус: **V2 SALES-WEIGHTED — current copy authority**  
Matrix source: `RECOMMENDATION_MATRIX.md`  
Decision audit: `SALES_WEIGHTED_MATRIX_V2_AUDIT_2026-08-28.md`

Этот документ отвечает только за **то, как объяснять уже выбранный V2-результат клиенту**. Клиентский текст не должен раскрывать продажи, ranking, внутреннюю матрицу или причины коммерческой оптимизации.

## 1. Порядок ответа

Всегда:

1. назвать Чертог;
2. коротко назвать 2–4 темы Чертога;
3. назвать рекомендуемый оберег;
4. объяснить, почему его смысл подходит;
5. сразу после товара дать ссылку на запрошенный marketplace.

Не начинать ответ с голой ссылки или названия товара без контекста Чертога.

## 2. Пол

Пол никогда не угадываем по имени, аватару, формулировке вопроса или дате.

- если пол указан — показываем только нужную ветку;
- если пол не указан и male/female результаты различаются — показываем обе ветки;
- если результат одинаковый — один общий блок без дублирования.

## 3. Marketplace

V2 может иметь marketplace-specific результат.

Сейчас утверждён только один такой case:

```text
Ворон + мужчина:
Ozon        → Колядник
Wildberries → Алатырь
```

Поэтому при наличии marketplace в запросе нужно использовать именно effective result для него.

Клиенту нельзя объяснять различие фразами «на WB лучше продаётся», «на Ozon больше заказов», «там есть/нет карточка» и подобными.

## 4. V2 всегда выдаёт один товар

В V2 нет secondary recommendation.

Даже для Медведя результат один:

```text
Медведь + мужчина → Печать Велеса — Медвежья лапа
Медведь + женщина → Печать Велеса — Медвежья лапа
```

Сварог в клиентской рекомендации Медведю больше не показывается.

## 5. Печать Велеса — специальное правило

Продаваемый SKU имеет форму **медвежьей лапы**.

Customer-facing label:

```text
Печать Велеса — Медвежья лапа
```

Он используется только для Чертога Медведя.

Для Чертога Волка используется отдельный товар `Велес`. Нельзя писать Волку рекомендацию `Печать Велеса`, потому что покупатель увидит медвежью лапу и возникнет очевидная путаница.

Approved Медведь copy:

> Дата относится к Чертогу Медведя. Этот Чертог связывают с внутренней силой, стойкостью, ответственностью, защитой близких и умением твёрдо стоять на своём.
>
> Рекомендуем «Печать Велеса — Медвежью лапу». Образ медвежьей лапы непосредственно перекликается с символом самого Чертога Медведя; этот знак связывают с силой, уверенностью, защитой и способностью преодолевать трудности.

## 9. Как писать curated recommendation

Нельзя говорить:

- «это fallback»;
- «прямого товара нет»;
- «выбрали более продаваемый вариант»;
- «этот SKU лучше конвертит»;
- «другой товар плохо продаётся».

Нужно говорить только о положительной смысловой связи выбранного символа:

```text
Этот Чертог связывают с <темы>. Оберег «<товар>» связывают с <близкие темы>, поэтому его смысл хорошо соответствует этой линии Чертога.
```

## 10. Жёсткий запрет: никогда не сообщать клиенту об отсутствии

В готовом клиентском ответе запрещено сообщать об отсутствии:

- товара;
- оберега;
- символа;
- карточки;
- ссылки;
- ассортимента;
- складского остатка.

Нельзя писать:

- «этого оберега нет»;
- «в ассортименте отсутствует»;
- «на WB нет карточки»;
- «поэтому предлагаем замену»;
- «товар закончился, возьмите другой».

Если destination/link не найден, это внутренняя операторская проблема. URL не выдумывать и клиенту отсутствие не объяснять.

## 11. Тон

Предпочтительно:

- спокойный;
- уверенный, но не категоричный;
- 1–3 предложения объяснения на товар;
- сначала Чертог и смысл, затем продукт;
- `связывают с`, `считается покровителем`, `по смыслу соответствует`.

Не использовать:

- внутренние слова `matrix`, `rank`, `fallback`, `selection_basis`, `relation_type`;
- технические слова про API/SKU;
- обещания гарантированного магического эффекта.

Запрещённые обещания:

- `точно защитит`;
- `гарантированно принесёт деньги`;
- `обязательно изменит судьбу`;
- любые аналогичные гарантии.

Для защитной тематики безопасная формулировка:

```text
Символ традиционно связывают с защитной символикой; его можно разместить в автомобиле как личный оберег.
```

## 12. Историческая осторожность

Календарь 16 Чертогов используется как продуктовая конвенция. Не выдавать спорные современные трактовки за бесспорный исторический факт.

Предпочтительны конструкции:

- `эту дату относят к Чертогу...`;
- `считается покровителем...`;
- `связывают с...`;
- `по Сварожьему кругу...`.
