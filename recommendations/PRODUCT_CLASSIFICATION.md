# Классификация славянских оберегов для рекомендательной системы

Статус: V1, рабочая классификация для утверждения перед разработкой.

Источник ассортимента: текущая нормализованная Ozon-выгрузка репозитория `blood_sand`. В семейство `slavic_symbols_oberegs` входят 25 SKU.

## Принципы

1. Классификация ниже — **продуктовая curated-политика рекомендателя**, а не заявление о доказанной древней исторической системе.
2. Не каждый SKU обязан использоваться в V1. Слабое соответствие лучше оставить неиспользованным, чем искусственно включать товар в выдачу.
3. `gender_policy` задаёт допустимость товара для клиентской выдачи:
   - `male` — используем только для мужчины;
   - `female` — используем только для женщины;
   - `any` — можно использовать для обоих полов;
   - `any_male_coded` — преимущественно мужской по характеру, но не блокируется для женщины при прямом соответствии Чертогу.
4. Для SKU `Печать Велеса` в рекомендательной системе используется фактическая товарная идентичность **«Медвежья лапа»**. Он не связывается с Чертогом Волка только из-за marketplace-названия.
5. Продажи не влияют на смысловое соответствие и не меняют `gender_policy`.

## SKU, сознательно не используемые в V1

Следующие позиции остаются в ассортименте, но **не должны попадать в автоматическую выдачу V1**, пока не появится более сильное основание:

- Чернобог;
- Триглав;
- Ратиборец;
- Молвинец;
- Громовик;
- Стрибог;
- Хорс.

Их исключение — не оценка качества товара и не оценка продаж. Это защита точности рекомендательной системы.

## Жёсткие ограничения

- `Печать Велеса / Медвежья лапа` → `Волк = FORBIDDEN`.
- `Жива`, `Макошь`, `Звезда Лады` не выдаются мужчине.
- `Родимич`, `Колядник`, `Знич`, `Всеславец`, `Медвежья лапа` не выдаются женщине в V1.
- `Сварог` и `Перун` не получают hard block для женщины, если являются прямым покровителем соответствующего Чертога.
- Резервные SKU не должны подмешиваться в выдачу ради повышения количества рекомендаций.
