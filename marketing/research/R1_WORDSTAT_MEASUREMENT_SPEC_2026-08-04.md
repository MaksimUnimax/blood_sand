# R1 — Wordstat Measurement Specification

Дата: 2026-08-04  
Статус: **методика и набор запросов готовы; числовой съём требует авторизованного Wordstat/API**

## 1. Зачем этот документ

Качественная семантическая карта уже создана. Следующий шаг — не придумывать частотность, а снять её непосредственно из Яндекс Wordstat по России.

Этот файл фиксирует:
- какие именно запросы измерять;
- какие типы частотности нужны;
- какие временные и региональные срезы нужны;
- как данные должны быть сохранены в репозитории;
- почему сейчас в документе нет выдуманных чисел.

## 2. Подтверждённые возможности Wordstat

Официальная документация Яндекса подтверждает:

1. Веб-интерфейс Wordstat доступен только авторизованным пользователям.  
   https://yandex.ru/support2/wordstat/ru/interface/new

2. Wordstat API также требует авторизацию: OAuth/доступ к API либо Yandex Cloud Search API с соответствующей ролью и API key/IAM token.  
   https://yandex.ru/support2/wordstat/en/content/api-wordstat  
   https://aistudio.yandex.ru/docs/ru/search-api/concepts/wordstat.html

3. Метод Top Requests возвращает данные за последние 30 дней; Dynamics — динамику по дням/неделям/месяцам.  
   https://yandex.ru/support2/wordstat/en/content/api-structure

4. Регион `225` соответствует России.  
   https://aistudio.yandex.ru/docs/en/search-api/reference/regions.html

5. Wordstat поддерживает операторы `!`, `+`, `" "`, `[]`, `()`, `|`; кавычки фиксируют количество слов, `!` — словоформу, `[]` — порядок слов.  
   https://yandex.ru/support2/wordstat/ru/content/operators

## 3. Почему нельзя подменять Wordstat веб-поиском

Публичный web search подтверждает существование конкуренции и интентов, но не даёт корректного числа запросов Яндекса.

Следовательно:

- найденные карточки Ozon/BEREGY/других магазинов = подтверждение коммерческого интента;
- найденные статьи = подтверждение информационного интента;
- **они не являются заменой Wordstat frequency**.

До прямого съёма число показов не фиксируется как факт.

# 4. Tier 1 — измерить обязательно

Для каждого seed ниже снять:

1. broad count — без операторов;
2. phrase count — в кавычках;
3. exact-form count — кавычки + `!` перед значимыми словами;
4. Top Requests — связанные реальные формулировки за 30 дней;
5. Dynamics — минимум 24 месяца помесячно;
6. device split — all / phone / desktop, если доступно без лишних затрат;
7. регион — Россия (`225`).

# 5. Tier 2 — расширение по результатам Top Requests

Эти запросы не нужно массово измерять заранее. Они добавляются после того, как Wordstat покажет реальные ассоциации и вложенные формулировки.

Кандидаты:

- печать велеса купить в машину;
- подвеска оберег в машину;
- оберег на зеркало заднего вида;
- славянская подвеска в машину;
- медвежья лапа оберег купить;
- волчья лапа оберег купить;
- кулон печать велеса;
- печать велеса для мужчины;
- печать велеса для женщины;
- печать велеса подарок мужчине;
- оберег автомобилисту в подарок.

Правило: Tier 2 становится приоритетным только при наличии измеримого спроса или сильной коммерческой связи с Tier 1.

# 6. Формат таблицы результатов

После прямого съёма создать CSV/Markdown с колонками:

| Поле | Назначение |
|---|---|
| query | исходная фраза |
| cluster | товар / авто / значение / подарок / физические свойства |
| intent | transactional / commercial research / informational |
| broad_30d | широкая частотность |
| phrase_30d | фразовая частотность |
| exact_30d | точная словоформа |
| mobile_30d | мобильные запросы |
| desktop_30d | desktop запросы |
| seasonality_peak | месяцы максимума |
| seasonality_low | месяцы минимума |
| associated_queries | ключевые связанные запросы |
| commercial_priority | A/B/C |
| page_candidate | product/category/guide/faq/no-page |
| measured_at | дата съёма |

Числа сохраняются именно как полученные данные, без округления «для красоты» в сыром файле.

# 7. Как определять приоритет после получения чисел

Частотность сама по себе не определяет ценность страницы.

Использовать три оси:

## 7.1. Demand
Фактический Wordstat спрос.

## 7.2. Intent proximity
Насколько запрос близок к покупке:
- «купить печать Велеса» — очень близко;
- «какой оберег выбрать в машину» — средне;
- «кто такой Велес» — далеко.

## 7.3. Competitive feasibility
Есть ли в выдаче окно для независимого специализированного сайта.

Приоритет страницы = сочетание этих трёх факторов, а не просто «самая большая частота».

# 8. Что уже можно утверждать без Wordstat

Публичная поисковая выборка подтверждает, что коммерческие и информационные намерения существуют одновременно:

- Ozon — товарная карточка Печати Велеса;
- BEREGY — собственные товарные страницы;
- специализированные магазины — Veles.bz, Master Run, Zarenica и др.;
- информационные сайты — Arcanum, Grimuar, VashObereg, 100kulonov и др.

Это достаточно, чтобы продолжать конкурентный анализ, но недостаточно, чтобы объявлять точный размер спроса.

# 9. Текущий блокер

В текущем рабочем контуре нет авторизованного доступа к Wordstat/Wordstat API. Официальная документация Яндекса прямо требует авторизацию.

Поэтому правильное действие сейчас — **не писать фиктивные частотности**, а:

1. завершить публичный competitive/search landscape;
2. подготовить готовый список запросов и формат выгрузки;
3. при появлении авторизованного Wordstat снять данные одной операцией и сразу внести их в R1.

Статус R1 остаётся `IN PROGRESS` до получения этих чисел.
