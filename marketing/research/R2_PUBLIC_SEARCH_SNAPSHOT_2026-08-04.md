# R2 — Public Search Landscape Snapshot

Дата: 2026-08-04  
Статус: **публичный web snapshot выполнен; это НЕ фиксированный Top-10 Яндекса**

## 1. Задача

Проверить, какие типы ресурсов реально индексируются и конкурируют вокруг:

- «Печать Велеса»;
- покупки Печати Велеса;
- автомобильных оберегов;
- подвесок на зеркало;
- значения/разновидностей символа;
- подарочного и автомобильного сценария.

Этот слой нужен до прямого съёма Яндекс SERP, чтобы понять структуру конкурентного поля и не проектировать сайт вслепую.

## 2. Ограничение

Использован текущий публичный веб-поиск и доступные индексируемые страницы.

Поэтому допустимы выводы:
- какие домены и форматы конкурируют;
- какие типы страниц уже существуют;
- какие данные показывают конкуренты;
- какие контентные пробелы видны.

Недопустимы без прямого Яндекс-съёма выводы:
- «этот сайт №1 в Яндексе»;
- «эта страница находится в Yandex Top-10»;
- «Алиса AI сейчас цитирует именно этот домен по запросу X».

### Промежуточный вывод по transactional layer

Коммерческая ниша **не монополизирована маркетплейсами**: индексируются самостоятельные магазины с отдельными товарными URL.

Но marketplace имеет сильнейшее преимущество по отзывам, привычному checkout и UGC. Поэтому наш собственный ресурс должен выигрывать:

1. первичной информацией о нашем конкретном изделии;
2. структурой и объяснением;
3. уникальными фото/измерениями;
4. связью товар → гайд → FAQ;
5. гибридным checkout, а не попыткой скрыть marketplace.

### Контентный пробел

Большая часть этих страниц слабо разделяет:

1. подтверждённую историко-этнографическую информацию;
2. поздние популярные трактовки;
3. современные эзотерические утверждения.

Для бренда это возможность сделать материал другого качества:

- чётко маркировать исторический факт;
- давать ссылки на академические источники;
- отдельно писать «современная трактовка/традиция»;
- не выдавать мистические эффекты за доказанные свойства.

Потенциальные академические отправные источники для проверки:
- Е. Е. Левкиевская, «Славянский оберег. Семантика и структура»;
- Институт славяноведения РАН: https://inslav.ru/publication/levkievskaya-e-e-slavyanskiy-obereg-semantika-i-struktura-m-2002

Это может создать реальное преимущество по ЭПОС: экспертность + оригинальность + содержательность.

# 6. Что видно по формату конкурентных страниц

## Независимые магазины выигрывают, когда дают:
- точные характеристики;
- несколько фото;
- обратную сторону изделия;
- размеры;
- вес;
- материал;
- варианты;
- доставку;
- собственную корзину.

## Маркетплейсы выигрывают по:
- объёму отзывов;
- вопросам;
- UGC;
- доверию к checkout;
- скорости покупки;
- ассортименту альтернатив.

## Информационные сайты выигрывают по:
- длинному тематическому охвату;
- отдельным информационным URL;
- ответам на «значение / для кого / отличие».

### Следствие для нашей стратегии

Один лендинг не сможет закрыть все три поля.

Нужен маркетинговый каркас минимум из трёх сущностей:

1. **product page** — наш конкретный SKU;
2. **category / use-case page** — автомобильные обереги/подвески;
3. **knowledge pages** — значение, отличие, выбор, крепление, подарок, материалы.

Это пока не техническая структура сайта, а **карта ролей страниц**. Реальное число страниц утверждается только после Wordstat + Yandex SERP.

# 7. Ключевой вывод текущего snapshot

Публичная выдача показывает важный для бизнес-решения факт:

> независимый сайт в этой нише не является экзотикой и может индексироваться как коммерческий и информационный источник одновременно.

Следовательно, гипотеза собственного ресурса остаётся жизнеспособной.

Но следующий критический вопрос всё ещё не закрыт:

> есть ли достаточный объём спроса и достижим ли именно Yandex Top-10 / Alice AI visibility по нужным нам запросам.

Для этого нужен прямой Yandex/Wordstat/Alice snapshot, который нельзя честно заменить обычным web search.
