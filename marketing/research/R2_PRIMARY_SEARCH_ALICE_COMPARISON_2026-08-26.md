# 3. Main cross-surface findings

## 3.1 Search and Alice are often solving different jobs for the same query

Strongest examples:

- `печать велеса`: Search is highly transactional; Alice is meaning/history/use-first.
- `алатырь оберег`: Search is commercial-first; Alice is mythology/meaning/suitability-first.
- `оберег велес`: Search is commercial-first; Alice explains symbol variants and suitability before light shopping.
- `вегвизир`: Search mixes entity + commerce; Alice strongly prioritizes historical/entity explanation.

This is direct evidence for a hybrid search-commerce asset: pages may need to be source-worthy for explanation while still satisfying purchase intent. The exact Page Job split remains a Roadmap 05 decision.

## 3.2 Automotive intent separates into two different jobs

`оберег в машину`:

- use-case/choice wording;
- mixed Search results;
- Alice actively recommends categories and products;
- symbolic purpose matters.

`подвеска на зеркало в машину`:

- form-factor wording;
- platform/marketplace-dominated Search;
- broad decor/accessory universe;
- symbolic/slavic variants compete with fandom, logos, personalization and generic ornaments.

Therefore these roots must not be treated as synonyms merely because the same SKU can satisfy both.

## 3.3 Zodiac broad demand is demonstrably contaminated

The contamination is confirmed independently by all three evidence layers:

- Wordstat: `3,422` broad → only `21` quoted;
- Search: guide/selection + stones/jewelry dominates;
- browser `Люди ищут`: stone + gender + sign branches dominate;
- Alice: stones/jewelry are central to the answer and source set.

A narrower zodiac query is necessary before judging the real opportunity for Blood & Sand's symbolic products.

## 3.4 Broad gift roots are not core acquisition roots for the pendant category

Both gift roots agree across Search and clean Alice evidence:

- default answer = practical gadgets/accessories/comfort/car-care/general gifts;
- pendants are not a dominant category;
- `подарок автомобилисту` Search can show an isolated Wildberries pendant snippet, but Alice still does not organically include the category;
- the earlier symbolic answer for `подарок мужчине в машину` was context contamination and is excluded.

Conclusion for Roadmap 04: **no gift secondary expansion now**.

## 3.5 Specialist independent sites repeatedly participate in both Search and Alice

Directly observed across Slavic/symbol roots:

- `slavyanskieoberegi.ru`;
- `ruyan-master.ru`;
- `veles.bz`;
- `slavyarmarka.ru`;
- other specialist content/commerce sources depending on root.

This is important feasibility evidence for the own-site strategy: Yandex does not restrict these topics to marketplaces only.
