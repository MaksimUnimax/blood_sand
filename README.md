# Blood & Sand

Репозиторий будущего собственного интернет-ресурса бренда «Кровь и Песок».

## Текущий статус

На этом этапе **код сайта намеренно не создаётся**. Сначала фиксируется маркетинговая логика продукта: зачем нужен собственный ресурс, какую роль он должен играть рядом с Ozon/Wildberries, какие поисковые и AI-каналы мы хотим охватить, как будем измерять результат и какие гипотезы должны быть подтверждены до разработки.

Основная рабочая документация находится в [`marketing/`](marketing/README.md).

## Базовый принцип проекта

Собственный сайт не должен копировать маркетплейс. Его задача — стать управляемым брендом источником товарных данных, экспертного контента и коммерческих предложений для обычного поиска, AI-поиска и прямых продаж, при этом маркетплейсы остаются частью воронки доверия и покупки.
