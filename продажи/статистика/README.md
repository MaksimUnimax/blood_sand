# Продажи / статистика

Эта директория — постоянное хранилище рабочих данных по продажам и рекламной статистике проекта «Кровь и песок».

## Текущее исследование

Площадка: Wildberries  
Рекламная кампания: `26225434` (`Реком Зод Чер`)  
Цель: проверить, зависит ли спрос/продажи талисманов со знаками зодиака от календарного месяца и усиливаются ли продажи конкретного знака в его сезон.

Канонический период для первого годового сравнения: **2025-09-01 — 2026-08-31**. Это 12 полных календарных месяцев и полный цикл всех знаков.

## Важное ограничение источника

`promo_fullstats` — статистика рекламной кампании Wildberries. Поле `orders` отражает рекламно-атрибутированные заказы, а не гарантированно все продажи товара на Wildberries. Поэтому эти данные храним отдельно от будущей полной статистики заказов/продаж по SKU и не смешиваем источники без явной маркировки.

## Структура

- `wildberries/26225434/campaign_snapshot.json` — снимок параметров кампании и текущего состава SKU.
- `wildberries/26225434/monthly_campaign.tsv` — агрегаты кампании по месяцам.
- `wildberries/26225434/monthly_zodiac_orders.tsv` — рекламно-атрибутированные заказы и сумма заказов по каждому знаку и месяцу.
- `wildberries/26225434/observed_zodiac_nm.tsv` — соответствие знаков и `nmId`, встреченных в данных кампании.

Каждый месячный импорт должен сохранять `request_id`, период и версию bridge, чтобы результат можно было проверить и повторно разобрать.
