# Tooling

Этот каталог хранит проектный инструментарий, который нужен для исследования, аналитики и подготовки сайта, но не является runtime-кодом будущего `site/`.

## Основной toolkit

`llm-api-bridges/` — LLM-agnostic browser/API bridges для контролируемой работы с внешними API через локально сохранённые credentials.

Цель: дать любой поддерживаемой LLM-поверхности (ChatGPT, Alice, DeepSeek и др.) одинаковый безопасный способ формировать исполняемую команду, а локальному расширению — выполнить ровно один allowlisted API request и вернуть структурированный result/evidence обратно в диалог.

Секреты, API keys и tokens в Git не коммитятся и в текст диалога не выводятся.
