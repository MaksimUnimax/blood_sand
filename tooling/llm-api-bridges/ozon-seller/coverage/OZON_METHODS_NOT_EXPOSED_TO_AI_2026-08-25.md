# Ozon Seller API — methods not exposed to AI

Date: **2026-08-25**. These decisions are frozen for this coverage snapshot.

## Не реализуем: меняет данные — 8

- `/v1/analytics/manage/stocks` — Не реализуем: метод управляет остатками и может изменить количество товара.
- `/v1/cargoes/create` — Не реализуем: метод устанавливает грузоместа в заявке на поставку и меняет её состояние.
- `/v1/cargoes/delete` — Не реализуем: метод удаляет грузоместо из заявки на поставку.
- `/v1/cargoes/transport/activate` — Не реализуем: метод включает или отключает транспортные грузоместа в поставке.
- `/v1/cargoes/transport/bind` — Не реализуем: метод связывает или отвязывает грузоместа и тем самым меняет поставку.
- `/v1/cargoes/transport/create` — Не реализуем: метод создаёт транспортное грузоместо и меняет поставку.
- `/v1/pricing-strategy/status` — Не реализуем: метод меняет статус стратегии ценообразования, а не просто читает её.
- `/v2/cargoes/delete` — Не реализуем: метод удаляет грузоместа из заявки на поставку.

## Не реализуем: выполняет внешнее действие — 1

- `/v1/notification/check` — Не реализуем: метод заставляет Ozon выполнить проверочный запрос к URL. Это уже действие наружу, а не простое чтение данных.

## Оставляем только внутренним методом Bridge — 1

- `/v1/seller/info` — Не даём этот метод напрямую ИИ: ответ содержит данные кабинета и компании, которые модели не нужны. Bridge использует его только внутри и передаёт модели только безопасные признаки подписки и доступности.
