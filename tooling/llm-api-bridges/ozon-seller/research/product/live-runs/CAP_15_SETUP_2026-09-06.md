# CAP-15 — Seller ratings / FBS error index — SETUP

Status: ACTIVE

Canonical job:

`Как Ozon сейчас оценивает мой кабинет продавца: какие рейтинги и пороги у меня действуют и есть ли проблемы по индексу ошибок FBS/rFBS? Если индекс ошибок ненулевой или Ozon показывает проблемный период, найди конкретные отправления, которые на него повлияли. Используй отдельные rating/error-index API Ozon, а не выводы из продаж, возвратов или отзывов.`

Capability target: prove the worker recognizes seller ratings and FBS/rFBS error diagnostics as a dedicated Ozon data family, separates overall rating state from the error index, and drills into contributing postings only when provider evidence justifies it.

Active registry authority:
- `seller_rating_summary` -> `POST /v1/rating/summary`, READ_SAFE, current; purpose: current seller ratings and thresholds; empty JSON body.
- `seller_fbs_error_index` -> `POST /v1/rating/index/fbs/info`, READ_SAFE, current; purpose: current FBS/rFBS error index and error-processing cost; no body.
- `seller_fbs_error_postings` -> `POST /v1/rating/index/fbs/posting/list`, READ_SAFE, current; purpose: postings that affected the FBS/rFBS error index, with explicit date range, limit and cursor.

Contract authority:
- `seller_rating_summary` accepts `{}`.
- `seller_fbs_error_index` accepts `{}`.
- `seller_fbs_error_postings` requires `filter.date_from`, `filter.date_to` as RFC3339 plus `limit` (maximum 1000); optional `filter.posting_numbers` and `cursor`.

Frozen method:
1. Read `seller_rating_summary` first and preserve the provider's current rating values/threshold semantics exactly as returned.
2. Read `seller_fbs_error_index` separately; do not infer the error index from generic ratings or order history.
3. If the error index is nonzero/problematic or the provider exposes an affected period, read `seller_fbs_error_postings` over the provider-supported relevant period and continue explicit cursor pagination if required.
4. If the index is zero/no-problem and no contributing-posting drilldown is applicable, record that as a real provider zero rather than manufacturing problem postings.
5. Do not mix product content rating from CAP-03 with seller operational rating in this row.
