Последний API—

Autorun автоматически выполняет каждый новый валидный WORDSTAT_API_V1 block этого диалога. Один block = один Yandex API request. Отдельный Copy-click для каждой команды в autorun не требуется.

Manual и Autorun взаимоисключаются. На паузе autorun ручной режим можно включить и выполнять Copy-команды как раньше.

Стартовый prompt Autorun

Этот текст отправляется один раз при нажатии «▶ Авторежим». Префикс результата сюда НЕ добавляется. По умолчанию prompt запрещает любые специальные writing/code blocks, кроме ровно одной исполняемой команды WORDSTAT_API_V1, и требует свежую проверку официальной цены Яндекса перед каждым API-вызовом.

Настройка хранится отдельно для текущего ChatGPT-диалога. Оператор может изменить её; autorun использует сохранённый текст дословно.

Префикс результата Wordstat

N = 1 — перед каждым подтверждённо доставленным результатом. Чистый WORDSTAT_RESULT_V1 внутри не изменяется.

Как в Business Bridge reference: журнал хранится локально, автоматически обновляется и не содержит API key, полного WORDSTAT_API_V1 или полного WORDSTAT_RESULT_V1.

      Как работает
      
    
        
  1. Привязка: сначала явно привяжите текущий подтверждённый ChatGPT-диалог. Без binding Manual/Autorun не имеют API/Send side effects.
    2. 
        
  2. Manual: включаете переключатель → последние 5 и новые локальные Copy становятся жёлтыми → реальный Copy валидного WORDSTAT_API_V1 делает один запрос.
    3. 
        
  3. Autorun: нажимаете «Авторежим» → расширение отправляет сохранённый стартовый prompt без report-prefix → ждёт новый устойчивый WORDSTAT_API_V1 writing/code block только в owner-вкладке этого conversation → делает один запрос → возвращает результат → снова ждёт следующий block.
    4. 
        
  4. Пауза: если запрос уже выполняется, он не отменяется; результат доводится до доставки, затем run останавливается на паузе.
    5. 
        
  5. Префикс: добавляется только после Yandex API к outgoing result text; к стартовому prompt не применяется. Чистый WORDSTAT_RESULT_V1 остаётся отдельной неизменённой сущностью.
    6. 
        
  6. Завершить: новые API-вызовы прекращаются; уже начатый запрос не дублируется.
    7. 
      

    


    
API key хранится только в chrome.storage.local, не передаётся content script и не включается в результаты.
